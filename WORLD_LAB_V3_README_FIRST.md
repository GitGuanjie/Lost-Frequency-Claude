# WORLD CONTINUITY LAB v3 — READ FIRST

This is a **source-only experimental upgrade** built on the supplied
ContinuityLab v2 source. It does **not** contain a newly certified Windows EXE.
Open `project.godot` with Godot 4.5.1, or on Windows double-click
`RUN_WORLD_LAB_V3_QA_WINDOWS.bat` after putting a Godot 4.5.1 console executable
on PATH (or pass the executable path as the batch file's first argument).

In the main menu choose **Experimental · Seamless 3D World Lab**.
Explore the 4-chunk continuous hall from chunk (1,0,1) to (2,0,2), including
its stacked atrium and bridges. Use E on the power relay in (1,0,1), F4 to
reshape noncritical fit-out, F8 to view the map, F9 to mark, F5/F6 to switch
world seeds, F10 to save and return. Existing worlds are preserved.

Full changes, limitations and QA instructions:
`docs/production/WORLD_CONTINUITY_LAB_V3.md`.
