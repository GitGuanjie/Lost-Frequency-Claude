# Lost Frequency v1.5.0-dev4 — 源码开发及验收报告

## 范围与状态

- 基线：用户提供的 v1.5.0-dev3 完整源码。当前版本：v1.5.0-dev4。
- 原先 47 个场景；新增 9 个具有独立场景脚本的关卡；**目前 56 个场景源码**。100 关名册没有变。
- 关卡清单共 173 条出口声明，88 条指向已构建关卡，43 条在**旧版历史 QA 快照**中曾被观察；后一个数字不是 dev4 新验证。
- 从 Level 0 按清单可到达 30 个已建关卡；旧版 QA 快照支持 21 个。未解决的剧情或碰撞故障不因静态连通率升高而消失。
- **没有 Godot 4.5.1 Linux 引擎或 Windows/Wine 可用**。未进行 Godot 脚本编译、重新导入、实机启动、真实画面、完整故事链或 GPU 性能测试。
- 全部 9 个新增关卡保持 `IN_DEVELOPMENT` 和 `NOT ENGINE VERIFIED`；只有开发者跳关允许预览。

## 系统与工具变更

1. `core/world/LevelBase.gd` 新增 `_register_provisional_arrivals()`：收到没有专门设计的 `from_Lxxx` 标签时，可使用显式记录的 `start` 安全位置别名。保留 `provisional_start_alias` QA 字段，不将安全兜底说成完整关卡入口。
2. 15 个目标关卡清单共添加 **40 个临时入口别名**。这使静态审计的缺失入口结构项从之前 41 项降为 0，但必须在真实场景中重新设计专门的入口空间。
3. 停车场分段挖开两层楼板供楼梯贯通；战壕挖开两处掩体入口；住宅拆分底层楼板，留出地下室楼梯开口。
4. 世界审计现在单独输出 `provisional_start_arrivals` 清单，防止消灭告警掩盖开发债。
5. `tests/static/test_dev4_world.py` 新增 6 个独立检验，静态测试总计 **22/22 通过**。
6. `tools/run_dev4_qa.py` 与 `RUN_DEV4_QA_WINDOWS.ps1` 提供逐关、严格检查新报告的 Godot QA，避免旧报告冒充新结果。
7. `reports/world_audit/` 已重新生成有向世界图、CSV 和 JSON 审计。

## Windows 产物验证说明

`LostFrequency_v1.5.0-dev4_Windows_x86_64_EXPERIMENTAL.zip` 保留上一版实验 EXE 的 Godot 4.5.1 引擎，替换/新增 43 个运行时文件，对嵌入式资源包索引的 **464 条资源项**全部进行了哈希校验，文件能被独立的离线解析程序重新读取。**它不是 Godot 原生导出，不能保证在 Windows 中可启动**；任何新代码 GDScript 编译失败，仍可能使 EXE 启动失败。用户实测后应提交 `DIAGNOSE.bat` 日志。
