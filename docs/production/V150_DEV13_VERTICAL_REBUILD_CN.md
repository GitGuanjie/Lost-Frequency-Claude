# Lost Frequency v1.5.0-dev13 — 空间纵深重制与验证报告

## 交付范围

基于 dev12，保留 100 个已建场景和 235 条原始出口声明。本轮只修改场景内部建筑结构与开发测试，不增加新的跨 Level 传送口。新增的是**设计阶段的局部几何路线**，不是通过 Windows/Godot 实机认证的玩家可行走路线。

## L002 — 管道厅第三高度检修循环

在第一处固定管道大厅 `(chunk 2,0)` 内，保留现有 y=4.2m 的中央上层钢格栅，增加两条分离的坡道，分别连接到 y=5.0m 的高位检修横向平台，形成两端可进入的小循环。坡道宽 1.25m，约 4.1m 水平路程，上升 0.8m。主厅天花板约在 y=7.9m，理论净高约 2.9m。新增管线铭牌调查点。注意：原始上层甲板是 y=4.2m，不是 y=2.8m；高度已经与源码统一。仍须验证旧的护栏、悬挂管线和坡道之间是否碰撞。

## L004 — 办公中庭高位巡检桥

在双层办公室中庭上方切开原第二层天花板范围 `BRIDGE_CANOPY`，新增 y=5.1m 的悬空横桥、南向观察支路、两端从 y=3.6m 上升的坡道。抬高新桥廊上方局部顶板至 y=8.35m，避免旧 y=6.4m 顶板造成低净空。新增灯具、护栏与一处调查铭牌，保留 M.E.G. 设施及原有楼梯和跨关卡出口。Godot 碰撞射线检查已编写，尚未执行。

## L005 — 酒店 B1 下方双入口检修环路

在锅炉区西侧新建深入到 y=-8.1m 的地下检修空间，原 B1 西墙指定位置切两个 2.2m 宽的实际通道。分别从 y=-5.0m 经下降坡道进入地下检修平台，并在底部连成回路。两条路径独立布置，避免把一个楼梯复制两次造成重叠。新增照明和维护示意牌，不更改原有 Level 6 出口。**风险：** 高温区内已有配管与动态物件，必须实机检查所有净空。

## L037 — 水下分层平台

在固定深水楼梯井 `(chunk 1,0)` 新增 y=-1.6m 与 y=-4.35m 的平台，以下降坡道连向 y=-7.5m 深水井底。避免旧支撑柱范围；新增水下光点，保留原水体、游泳和无实体设定。水下环境下，这些是可接近的几何路径，不应错误假定玩家在全部深度均可直立步行。

## 数据、QA 与验收边界

- `data/vertical_routes_dev13.json`：4 个关卡的设计阶段路线节点与连线、宽度和原始关卡清单 SHA-256。图不声称物理可通行。
- `tests/static/test_dev13_spatial_rebuild.py`：检查设计图连通、坡度、宽度、源文件、原关卡清单未改动以及测试脚本的证据约束。
- `tests/ModelAssetSmokeDev13.tscn`：针对 414 个 GLB 模型的导入/实例化测试，成功后仍需要游戏实机 QA。
- `tools/run_dev13_qa.py`：原生 Godot 导入、模型烟雾、关卡、碰撞自检、Level 9 路牌路线与剧情流程。没有新 JSON 证据就不能通过。Windows 手动试玩另行确认。
- `VERIFY_DEV13_OFFLINE.py`：仅证明 Python 静态检查和世界清单一致性，不证明 GDScript 可被引擎编译。

**No new cross-level exits were added.** 这四关的场景文件和原有世界连通关系列表不变。原始 Backrooms 来源限制继续有效。
