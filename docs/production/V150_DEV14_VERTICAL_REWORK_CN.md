# Lost Frequency v1.5.0-dev14 — 多层立体地图重构（开发源码）

**版本状态：开发中、未通过 Godot 引擎或 Windows 实机验收。** 本次在用户上传的完整分卷源码基础上修改。仍是 100 个登记关卡的工程，不是 100 关全部可玩的稳定版。新增的连通设计图不是实际角色走通的证据。

## 目标与实际改动

- **L000 黄色迷宫：** 现有中庭随机出现四层、五层纵向延伸；每层保留中央贯通井，横向连桥、交替东西侧楼梯、可见井壁、不同的夹层隔断、交互牌和灯光。楼梯在上层楼板开了洞，不是简单把一块平台浮在头顶。稀有变体依赖种子，普通中庭仍按旧版生成。
- **L001 仓库：** 在原有二层检修廊上方增建第三层检修环路，专门割开 3 米宽上行楼梯井；东西两条可替代路径、护栏和现场记录。
- **L009 夜路：** 非剧情终点的郊区停车楼扩展至第四层，增建折返楼梯、无盖井洞、环形屋顶路线和向外悬挑的侧廊。剧情终点 `end_owner` 的机关和出口没有修改。
- **L011 城市：** 公园内第三层立体天桥上增加双楼梯通往第四层空中横桥；可从两端上下形成另一条环路，原有跨层出口和地面路径不改。

这些都是新增的物理楼板、梯段、碰撞体和局部互动，不是单独摆放不可到达的装饰模型。**但尚未验证每处台阶实际可让玩家步行抵达。**

## Windows 自行验证和导出

1. 安装 Godot **4.5.1** 和对应 Windows Desktop export templates；安装 Python 3。
2. 用 PowerShell 在本工程根目录运行：

```powershell
python VERIFY_DEV14_OFFLINE.py
.\RUN_DEV14_QA_WINDOWS.ps1 -GodotExe 'C:\path\to\Godot_v4.5.1-stable_win64_console.exe' -Story -Full
```

3. 仅在上述引擎 QA 全通过后，才能执行实验性导出：

```powershell
.\EXPORT_DEV14_WINDOWS.ps1 -GodotExe 'C:\path\to\Godot_v4.5.1-stable_win64_console.exe' -Story -Full
```

实验性 `.exe` 还需人工检查帧率、楼梯实际走通、实体与场景碰撞、F3/F6/Esc 调试菜单、存档读取、L009→L011 原剧情链。**不能因为可导出就标记为正式版。**
