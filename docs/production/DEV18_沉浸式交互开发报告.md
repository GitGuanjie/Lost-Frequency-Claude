# DEV18 — 空间交互与原站氛围对齐

## 目标

既有 dev14–dev17 聚焦楼梯、洞穴通道、环路和结构连通的设计图。DEV18 保留其结构，补齐玩家在局部空间的互动反馈，不将开发次数、节点数误报为已完成的可玩关卡。

## 实际增量

|---|---|---|---|---|
| L000 | 可触摸的潮湿壁纸 | 三道划痕，房间变化后消失 | 局部版本及日志 | 黄墙、潮湿、布局变化；划痕为改编 |

### 通用机制

1. `LevelBase.make_interactable(center, size, prompt, cb, owner)` 把物理交互体放入对应 `ChunkWorld` 分块里，卸载时销毁，防止残留的幽灵提示。
2. `AmbientDiscovery.gd` 读取 `data/dev18_ambient_discoveries.json` 的 17 个事件；0.25 秒低频检查，按距离及楼层垂直高度限位，一个事件只响一次，事件间隔 12 秒；QA 模式禁用自动播放，减少物理测试噪声。
3. `SaveService.record_discovery()` 将已发现的地点、文字与原站氛围/游戏改编标记写入单独探索日志；旧存档无需预有字段；UI 的 J 日志显示最近最多 30 条。
4. `CANON_MOTIF` 表示来源为原站描述的**特征/氛围**，`ADAPTATION` 表示具体互动由游戏原创；两者都不主张文字为站点原句。
5. 无新增出口、怪物生成或自动传送。未触及 100 关登记和 235 条出口。

## 运行核验

执行 `python -m unittest discover -s tests/static -p 'test_*.py' -q`（当前 156 tests PASS）。`tools/run_dev18_qa.py` 增加新的原生 `interactions_dev18` 测试：载入 L008 和 L037 的七个位置、检查碰撞体/交互回调、卸载分块并确认交互体删除；仍然保留 dev14–dev17 和 414 GLB 资产测试。测试按 **fail closed** 运行；当前平台缺少 Godot 4.5.1，未获得实际引擎通过凭据，发布不得标为“已完整可玩”。

## 后续高优先级问题

1. 从 Godot 实际跑通 QA，再拍摄 7 个互动地点实际截图，修正错位的墙体/灯光/触发盒。
2. 用玩家胶囊控制器验证跨层楼梯净空、地下洞穴斜坡及障碍物绕行，不只通过路线设计图。
3. 为 100 个场景建立来源/地貌/标志性内容覆盖表；逐关扩展不同的结构语法，避免每关都是四层重复建筑。
4. 优化移动平台上弱光反射的性能与音效响度；Poolrooms 不应被震耳欲聋的跳吓式音效破坏。
5. 增加真正的场景标识、独特几何和可观察环境变化，比继续堆积 100 个装饰模型更重要。
