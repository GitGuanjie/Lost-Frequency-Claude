# ContinuityLab v4 — structural design and acceptance

## Architectural objective

Make a continuous seeded procedural volume rather than disjoint room scenes,
while preserving the original 100 Backrooms canon levels. v4 is a focused
non-canon developer lab, not a replacement for story transitions.

## Nested spatial hierarchy

| Level | Extent | Ownership | Guarantee |
|---|---|---|---|
| Chunk | 24 × 24 × 4.5 m | `(x,y,z)` | shared four-side openings and stair pairing |
| Macro | 4 × 4 chunks | `macro_key` | core 2×2 atrium, conditional void/bridge |
| Superdistrict | 8 × 8 chunks | `super_key` | 2-chunk-wide orthogonal spines, 2×2 hub, survey console |
| World | unbounded in horizontal x/z | seed + chunk keys | load/unload radius; bounded five storeys for now |

The superdistrict central chunks have local coordinates `(3,3),(4,3),
(3,4),(4,4)` mod 8. Superhub floor holes occupy the four inner corners
and align into an 8 × 8 m void. Each floor above y=-2 has two suspended
bridges from west to east; collision floors are generated by the same
`_floor_with_slot_and_atrium` code used by the original 4x4 atria.

All routing decisions are pure functions of seed and integer chunk key.
Non-canon F4 room shifting affects only decorations and room class.
The old story Level 0, Level 1 and all transition records remain unchanged.

## Generation and performance budgets

`ChunkWorld3D` default radius remains 1 horizontal / 1 vertical; target
3×3×3 loaded chunks, 2 builds per frame; stale chunks unload outside
radius 2. Each GeoKit chunk keeps meshes batched by material and uses
separate box collisions. Adding the 8x8 region is **planning**, not loading
64 full chunks at once. Frame time still needs measurement in native Godot.

v4 changes the lab's save path only through its existing per-seed lab JSON;
no `SaveService.save_story()` calls. Visit markers are debounced (12s) and
all explicit menu/seed changes flush. The only base component modified is
`core/world/ChunkWorld3D.gd`, which is the experimental streamer and is
not used by canonical `ChunkWorld.gd` clients.

## Test gates (in order)

1. `python -m unittest discover -s tests -p 'test_worldlab*static.py' -v`
2. Godot 4.5.1 import and `tests/CompileAll.tscn`
3. Godot topology scripts v2, v3, v4
4. Manual collisions across four orientations and negative world coordinates
5. Manual 5-floor ascents, rails/bridge crossing, no unintended falls
6. 8×8 terminal interaction, light refresh, persistent seed save/reload
7. 10-minute streamed walk, CPU/GPU fps/frametime/peak VRAM profile
8. Export Windows, test on a Windows GPU, check story and 100-level registry

Only the first gate has been completed in the source-authoring environment.
If any native or manual step fails, retain v3 as the playable fallback.

## Next implementation milestones

A. Headless build/collision walker automatically crosses hub bridge and
   stair segments in Godot; measure no blocked routes.
B. Structure grammar: connect multi-macro corridors with physically
   supported side rooms, inter-floor shafts, lifts, traversal puzzles.
C. Implement a persistent multi-scene WorldCoordinator that can stream
   real Level 0 and Level 1 scenes without losing the player; still use
   canon transitions for non-Euclidean no-clips.
D. Visual pipeline: source-appropriate bespoke 4K far-view matte paintings
   and low-poly parallax shells, with rights and source attribution verified.
E. Add persistent loot/interactions/AI only after good frame pacing and
   walkable topology are proven; benchmark real Windows builds.
