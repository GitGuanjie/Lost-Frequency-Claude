# Lost Frequency v1.5.0-dev3 开发报告

本轮以 v1.5.0-dev2 源码为基线，新增 **8 个独立开发中关卡**：L031（溜冰场）、L048（落日海滩与可进入的两层旅馆）、L000_3（冰封走廊）、L006_1（Snackrooms）、L021（编号门迷宫）、L808（合成波地形）、L922（四层连续循环楼梯）、L149（低重力浮空椰岛）。

- 所有新增的出口 ID 均来自既有 `data/canon/transitions.json`；没有新造跨关卡目的地。
- 新关都有真实场景脚本、关卡清单、至少两个截图机位（L922 只有两个、L031 两个）、来源约束的交互/视觉机制。
- 新增 World QA 程序 `tools/run_dev3_qa.py` 与 `RUN_DEV3_QA_WINDOWS.ps1`。它们不会使用历史报告替代新验收。
- 仍处于 `IN_DEVELOPMENT`，不能称已经可玩。正式 QA 需要 Godot 4.5.1 运行、场景导入、碰撞/导航、真实 GPU 截图与人工试玩。
- 地图审计的有向连通不等于玩家可实地通行。世界若有单向或没有入口的孤岛，**不会通过虚构出口来修复**。
- 旧 QA 文件不能用于本次版本的新增关卡。发行时必须先引擎构建验证再升级状态。

## 下次迭代优先级
1. 原生 Godot 导入并测试 L031、L048、L149 和 L922；重点观察几何遮挡、出入口距离与台阶碰撞。
2. 对 30 个缺失目标 arrival 标签逐一按实际场景安全落点修复，不要默认所有标签使用中心点。
3. 复测 Level 9 → 11 路牌路线、存档恢复与跨关转场。
4. 为 8 关拍摄来源标明的 GPU 截图，人工审查 visual quality；尤其 L808 的光照、L149 的远处裁剪。
5. 优化遗留 L000、L013、L011、L004 的碰撞/批渲染热点并保持故事路径。
6. 发布只有通过 QA 的新增关卡，开发中关卡保留开发者跳关供测试。

## 本轮离线结果（2026-11-07）

- 100 个目标名单中的 47 个现有场景源码（包括 8 个 dev3 新增候选）。
- 全部清单中 157 条出口声明；70 条指向两个都有场景文件的关卡。
- 从 L000 按有向清单可到达 26 个场景；使用**旧 QA 快照**观察到的连接只支持 18 个。后者不能作为 dev3 新关的成功证明。
- World audit 仍报告 30 个缺失目标 arrival 标签，未通过无根据的安全点映射隐藏。
- 16 项 Python 离线集成/来源静态测试通过，8 个新增 GDScript 脚本通过字符串与分隔符粗检。这些检查**不相当于 GDScript 编译**。
- 离线 Windows EXE PCK 资源包重新构建，并独立重新解析核对全部 437 条目录资源 MD5。**不是 Godot 官方导出，也没有在 Windows 启动测试。**
- 真实 Godot 4.5.1 原生构建无法在当前 Linux 环境运行（无 Godot 可执行文件，外部下载未成功）。

## 可玩性与开发可见性

只有以前已验收的关卡可进入 STORY 模式；新增八关维持 IN_DEVELOPMENT，可以通过 F3 开发者关卡浏览器进入进行体验与测试。此前已经存在但还未验收的关卡同理。不能把从 L000 按清单可达 26 关说成普通剧情可完全游玩 26 关。
