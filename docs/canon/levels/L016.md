## Signature mechanic and in-game implementation plan
SOURCE FACT: terrain alters at unknown intervals between rainforest (low gravity, dawn) and arctic (ice, 13h cycle); exit position moves but destination (Level 46) is fixed.
- Layout grammar: two authored biome states (rainforest and glacier) swapped by seeded timer; exit prop relocated each state (sand-covered tree vs sand-covered ice sheet).
- Materials/lighting: grass/foliage with fog and dawn light for A; reflective luminous ice, glacier slabs, rock for B.
- Audio: wind/fog and ambient forest for A; cold wind and ice creaks for B; orbs hum as warning cue.
- Mechanic: warning orbs, then a transition with rising glaciers, gushing rivers, freezing; player can be encased if caught (damage/frostbite). Low-gravity jump for State A on player only (foreign object).
- Exit trigger: interact with sand-covered tree (A) or standing zone on sand-covered ice (B) to Level 46.
- Entities: Light Guides only in State B (groups); none in A.
- Verticality: tree climbing (A), glacier spires (B).
- ABSENT: bases, day-night in State A, any fixed exit position.

## Canon traps (do not)
- Do not give State A a day-night cycle or State B a fixed dawn.
- Do not add a stable base or settlement.
- Do not make low gravity apply to native fauna.
- Do not treat the "Undetermined" theory text as hard physics; it is a group theory.
- Do not invent a third terrain state.
