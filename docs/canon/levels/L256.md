## Signature mechanic and in-game implementation plan
SOURCE FACT → IMPLEMENTATION
- Empty, still, over-dark exhibition center, neon blue → a compact interior set of modern corridors, display rooms, terminals, big windows onto featureless black; emissive neon-blue strips; unlit void outside windows.
- All doors locked, wall behind a kicked door → doors are decor; no door traversal; blank wall behind.
- Terminals: five sourced program types (static common, distorted camera feed of the player, early 3D demos, repetitive games, loud tones on black). Implement as screen shaders; the loud tone is a timed audio event.
- Stillness: no movement besides screens; no air sound; clocks that show differing times when unobserved (observation-based swap).
- Draft layering as presentation: opening terminal and ending error may frame a note collection (examine notes) in lieu of a combat structure.
- Exit: none sourced. For gameplay, any exit would be non-canon; mark as design decision or a terminal-failure ending.
- Verticality: none. Entities: none. Audio otherwise silent except terminal sounds.
