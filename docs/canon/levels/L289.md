## Signature mechanic and in-game implementation plan
SOURCE FACT: flooded dark scaffolded basement; one unseen very fast screaming entity; only exit loops.
- Layout grammar: small authored basement with water volume at about waist height, scaffolding and pipe geometry as procedural boxes/cylinders; do not exceed what the log supports (compact is fine).
- Materials/lighting/audio: murky water shader, concrete, metal scaffolding; very dark, flashlight use; water slosh, radio static; voice-over optional.
- Stateful mechanic: a single scripted event where an unseen presence rushes the player; screaming heard only by the targeted player (audio), then the player is relocated (to a Level 287 stub).
- Exit: a corrupted-number door/exit that returns the player to the same level (walk-in/condition loop).
- Verticality: none stated.
- Entity policy: one scripted unnamed entity, never fully visible. Absent: other creatures, items, base camps, extra towers.
