## Signature mechanic and in-game implementation plan
SOURCE FACT -> IMPLEMENTATION
- Dusty cluttered attics with sloped ceilings -> authored room kit (triangular-ceiling attic bays with doorframes, jutting alcoves) in a seeded chunk grid; plaster, wood floorboards, pink insulation patches; heavy box and furniture clutter.
- Boxes: interior pristine, exterior damp/dusty; taking an item out has a seeded chance to start rapid decay (item flag rots over time); food items inside boxes.
- Orange Glow under some floorboards -> emissive orange strips beneath selected boards; proximity applies comfort effect (nausea/hallucination meter, memory alteration shown as note text being replaced), no power over the player beyond lure.
- Decay/hallucination status: nausea, dizziness, blackout flicker, optional whispering audio (testimony only; keep optional).
- Exits: non-glowing board = fall to randomised target (38/202/432/654); broken door = seeded pick (289/5/12/20); handheld game item = 40/212; map edge blurring = 140. Glowing boards never an exit in the final write-up.
- Audio: creaking boards, dust-room tone, faint warm hum near glow. No natural light, dim glow lighting.
- Verticality: floor-only; fall exits through boards.
- Entity policy: none. ABSENT: bases, NPCs, combat.
