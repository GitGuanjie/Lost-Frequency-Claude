## Signature mechanic and in-game implementation plan
- SOURCE FACT: empty Western-style grid city with block formations, variable density, bland identical buildings -> seeded chunk streaming of city blocks (concrete/asphalt/brick/glass materials), density gradient noise from skyscraper blocks to low-rise strip malls, parks as the only green.
- SOURCE FACT: 1/3 of buildings unenterable with mirror-black windows -> seeded per-building flag; unenterable buildings use dark glass material and locked doors; the rest get sparse interiors with working lights/taps.
- SOURCE FACT: unobserved fluidity -> when a vehicle, billboard or roadworks prop is outside the player's view cone, a seeded system may relocate/change it; items moved out of place vanish.
- SOURCE FACT: one-way exits tied to building types -> ExitTriggers on buildings by type (Fun Zone -> Level 20 certain; water supply store -> 119; elevators on street -> 998 etc.) with conditional/seeded probabilities for 'chance' edges.
- Lighting/audio: quiet, low room tone, wind in streets (the page gives no explicit sound or time of day: not stated; keep neutral and do not add day/night claims).
- Communities: authored anchor settlements (Capital market, New Times Square, Base Beta sign for Level 115) as optional non-hostile NPC-free landmarks.
- Verticality: skyscraper blocks and subways/canals are sourced; interiors sparse. Entities: Facelings/Hounds only if added; Level 11 Effect means low aggression.
- Must stay ABSENT: native entities, combat quests, invented exits not on the page.
