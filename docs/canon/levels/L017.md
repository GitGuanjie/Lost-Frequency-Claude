## Signature mechanic and in-game implementation plan
- SOURCE FACT: 217 identical athwartship passages separated by reinforced bulkheads, 42 compartments each -> chunk-streamed ship interior: a long axis of repeating passages, each ending in a bulkhead door; compartments as seeded rooms (barracks, kitchen, comms, engineering). Metal and painted steel materials, riveted plates, low pipes.
- SOURCE FACT: independent time per compartment -> per-sector clock props (stopped / inconsistent) and no global timer; keep it subtle.
- SOURCE FACT: sector table -> authored anchors at stated sector numbers (1, 8, 12, 33, 47, 67, 104, 156, 165, 185, 200-206, 217) using only the listed observations; the rest is repeated filler.
- Lighting/audio: not described. Use sparing steel-hull room tone and cold-drop fog for sectors 200-206 (-6 to 10 C); machine in 217 with blue emissive light, high pitched tone and knocking.
- Entrance and exit: the closet (door interaction) is both. Verticality: not stated; athwartship passages, bridge, engineering suggest decks but the page gives no deck count.
- Entity policy: static human figures only; Sector 12 man does not attack; skinless man blocks. Keep body-horror tasteful/implied (content warnings).
