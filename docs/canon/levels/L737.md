## Signature mechanic and in-game implementation plan
SOURCE FACT → IMPLEMENTATION
- Endless gold dust under a fixed zenith yellow sun → unlit/emissive golden sky, no day cycle, shimmering gold sand shader; heat meter rising constantly on dust.
- Hazard-safe islands: ruined stone/marble blocks stop the burn, so route play from block to block (stepping-point platforms) instead of free walking.
- Landmarks are authored anchors: Great Pyramid hub with Site 737-1 ruins; Eiffel, Sphinx, Big Ben (07:37), Golden Gate over nothing, half-buried Statue and Burj tip as sparse seeded set pieces.
- Pyramid interior (Site 737-2): 60 m halls, tomb ring (7,373 name stones, sample generated names such as quoted), abyss chamber, narrow platform with reliefs, tombstone, Entity 737/1 hanging at the end (static, non-hostile).
- UltraSuit item flag: protects from heat; without it burn damage.
- Exits: listed levels via designated doors with seeded options; keep the memory-erasure beat optional.
- Verticality: pyramid depth and abyss are the vertical features; desert flat.
- Entity policy: only the sourced; Fireteam Midas optional patrol if the intruder-protocol is dramatised.
- ABSENT: wildlife, water, a settlement in 737 other than the Repository facility.
