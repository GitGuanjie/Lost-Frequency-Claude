## Signature mechanic and in-game implementation plan
SOURCE FACT -> IMPLEMENTATION
- Daytime skybox with flat grass islands -> authored island chunks (flat slab, thin grass, rock underside) separated by huge gaps; scaled gap (distances compressed, for example reached by long bridges); bright sky environment, no sun detail.
- Memory Lurker interaction -> stateful "trance": touching one starts a scripted fade where the world is replaced by a flatter, plastic, 2D-feeling variant (palette flatten, remove fog depth, robotic ambient voice). Player controls then become restricted (stiff speech/no sprint).
- Level voice -> whispering from all directions, non-positional audio offering "gateway" text.
- Dark-island/bridge draft = alternate "false form" variant after the trance; bridges clip into one another, some ending in void, some in Blue Channel.
- Time dilation: mild clock scale for the HUD timer (class line only).
- Exit: none; unknown. Provide a trance that never resolves, or an ending screen; do not invent an escape.
- Entity policy: SOURCED ENTITIES ONLY: Memory Lurkers, Wormlings (in dirt), level voice; Smiler and Birds as optional rare/rumor only.
- ABSENT: bases, working weapons against Lurkers (a crowbar hit is a testimony), safe zone.

## Canon traps (do not)
- Do not give a definitive exit; all exits are "Unknown".
- Do not treat the draft's bridges as canon geometry; it is a Lurker-induced false form (per block C interpretation).
- Do not make Lurkers killable for reward.
- Do not add a settlement; an outpost "once existed" and was destroyed.
- Do not merge blocks into one consistent story; keep conflicting forms.
