## Signature mechanic and in-game implementation plan
SOURCE FACT → IMPLEMENTATION
- Infinite corridors, seven floors, wooden stairs → seeded chunk-streamed grid of marble/granite aisles with bookshelf rows; seven stacked floors linked by wooden staircases; iron-railed void edge on corridors.
- Memory theft after 1–2 hours → stateful exposure timer; after ~60-120 min of play (scaled), inflict headache effect (screen pulse, muffled audio) and strip simple inventory/notes flags; drop a "notebook" prop containing the stripped note text.
- Exchange of knowledge for memory → readable books that give notes/clues; reading costs a memory flag.
- Emotion communication → mood cues via audio/pulse; anger triggers a bookshelf-collapse scripted event.
- Exit: seeded probability wooden dead-end door that returns player to the library start (loop); a door to Level 5 only as design extension flagged as not stated.
- Lighting/audio: warm dim light, dust-quiet room tone, page rustle, wood-step footsteps; reverb large hall. No entity agents.
- ABSENT: combat, wandering monsters, a visible Library Mind avatar.

## Canon traps (do not)
- Do not add monsters; the Library Mind has no body.
- Do not make the library finite-wide; only the floor count (7) is bounded.
- Do not let memory loss be announced to the player; page says victims usually do not notice.
- Do not present the Gentleman scene as a regular encounter.
- Do not invent a stated exit to Level 5.
