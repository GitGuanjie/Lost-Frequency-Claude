## Signature mechanic and in-game implementation plan
SOURCE FACT: absolute darkness, absolute silence; flashlights fail; feel-based navigation; psychological pressure.
- Layout: procedural concrete tight-hall maze (seeded chunks); authored anchors: entrance stub, stairwell to 7 (with faint wave audio), cold metal door, trip-wire spot.
- Lighting policy: flashlight and all light sources disabled; environment fully black; no emissive. Navigate via collision, hand-drawn map note as optional readable.
- Audio: near-silence (soundproof), footsteps on concrete very muffled; rare "hallucination" cues (scuttle, breath, whisper) that are not tied to any agent. Waves audible only near the Level 7 stairwell.
- Stateful mechanic: dread meter rising with time spent (minutes); wrong-turn flag can seal the way to 7 and back to 5.
- Exits: stairs trigger to 7 (conditional), door trigger to 129, wire interact trigger to 6.1.
- Verticality: only the stairwell down; otherwise flat.
- Entities: none. Optional rumored Mimicry as audio-only text note, never an active agent unless explicitly designed as a sourced community.
- ABSENT: lights, visible monsters, combat, weapons.
