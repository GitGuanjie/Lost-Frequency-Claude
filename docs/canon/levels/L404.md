## Signature mechanic and in-game implementation plan
SOURCE FACT → IMPLEMENTATION
- Glitching geometry and a flickering floor → a small, mostly empty procedural void-world using unlit-void and emissive panels; mesh vertices and floor tiles intermittently stutter, z-fight or flicker (shader only).
- Skybox/"sky" shards → a distinct sky dome with shards one may pick up (a "sharpest piece of the sky" interact).
- Memories cloud the mind and still the hands → periodic input-stall or blur effect; second-person text overlays in lower-case, as the page's voice.
- Solitude → no NPCs, no entities.
- Entry: condition trigger "catatonia" (e.g. a sleep/idle state) from an adjacent level.
- Exit: none stated; offer no exit or an explicit design-flagged soft exit (must be marked not-in-source).
- Audio: hard-drive-like clicks, soft digital hum, sweet air as quiet room tone; no source-supported music.
- Verticality: none stated.
- ABSENT: monsters, items, bases, doors.

## Canon traps (do not)
