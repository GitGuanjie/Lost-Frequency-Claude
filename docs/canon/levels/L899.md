## Signature mechanic and in-game implementation plan
SOURCE FACT -> IMPLEMENTATION
- Floating island over an endless void with aurora-like colored sky -> a single compact authored island: grass top, spring-fed lake, mushroom crops, small community hall; emissive colored sky shader, no sun/fog artifacts; no electric lights.
- Residence timer: a visible "days stayed" counter; past a few days the player is "reserved", ageing visuals increase and exit trigger disappears (fail/end state).
- Entrance: letter plus pigeon prelude at a base hub (or a start scene) and a long walk with Karl as a scripted follower guide.
- Exit: Karl guides back as an ExitTrigger available only before day threshold; return walk is shorter.
- Audio: gentle pads, wind, lake; faint banging pipes only in the diary framing, not in the level.
- Karl and staff: non-hostile idle NPCs. Verticality: none (single island). ABSENT: combat, night creatures.
