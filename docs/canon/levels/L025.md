## Signature mechanic and in-game implementation plan
SOURCE FACT: sparse working cabinets, each tethered to another level, powered by quarters, with a return cabinet always within about 100 ft.
- Layout grammar: authored arcade rooms (echoey, maroon walls, dust, shelves) joined by narrow back-hallways with boxes and boilers, bounded to roughly 8.5 by 9.2 mile conceptual size via seeded chunks (the actual playable can be smaller); wrecked cabinets as instanced props.
- Materials: carpet or concrete floor, maroon plaster, polystyrene tile ceiling, metal boilers; emissive dim screens only on working cabinets.
- Audio: echoey room tone, dripping, faint electrical buzz; chiptune only from working cabinets.
- Mechanic: collect quarters (inventory flag) from boxes/corners; a rare working cabinet (seeded 1 in ~1500, boosted for gameplay) opens an ExitTrigger of type `item` with a destination from the stated list; arrival at the destination places a return cabinet within ~100 ft.
- Level 10 cabinet is broken (water damage); show it as dead.
- Entrance door from Level 4 janitor-closet style.
- Verticality: none stated.
- Entities: none.
